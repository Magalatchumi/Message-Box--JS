# Message Box with Character Counter

A simple message box that displays a real-time character counter and limits the user input to 200 characters.

## 🚀 Features

### 📝 Message Input

* Allows users to type messages in a text area
* Supports up to 200 characters

### 🔢 Real-Time Character Counter

* Updates automatically while typing
* Displays the number of characters entered
* Shows the maximum character limit

### ⚠️ Character Limit Validation

* Prevents users from typing beyond 200 characters
* Displays a warning message when the limit is reached

### ✅ User-Friendly Interface

* Simple and easy-to-use design
* Instant feedback for user input

## 🛠️ Technologies Used

* HTML5
* JavaScript
